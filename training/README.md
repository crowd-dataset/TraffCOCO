# TraffCOCO YOLO Training

This directory contains the training and evaluation code for the
TraffCOCO YOLO object detection model.

The training pipeline uses the YOLO dataset generated by the annotation
pipeline.

## Dataset

The generated dataset is located at:

../outputs/YOLO_FORMAT/

Expected structure:

YOLO_FORMAT/
├── images/
│   ├── train/
│   ├── val/
│   └── test/
├── labels/
│   ├── train/
│   ├── val/
│   └── test/
└── data.yaml

The annotation pipeline is responsible for generating this dataset.

The training pipeline does not modify the generated dataset.

## Training

From the TraffCOCO project root:

python annotation_pipeline/training/train.py \
    --model path/to/model.pt

The dataset YAML defaults to:

annotation_pipeline/outputs/YOLO_FORMAT/data.yaml

A custom dataset can be supplied with:

python annotation_pipeline/training/train.py \
    --model path/to/model.pt \
    --data path/to/data.yaml

## Validation

python annotation_pipeline/training/validate.py \
    --model path/to/best.pt

## Test Evaluation

python annotation_pipeline/training/test.py \
    --model path/to/best.pt

## Prediction

python annotation_pipeline/training/predict.py \
    --model path/to/best.pt \
    --source path/to/image_or_directory

## Training Outputs

Training runs are stored under:

annotation_pipeline/training/runs/

Typical output:

    │   ├── best.pt
