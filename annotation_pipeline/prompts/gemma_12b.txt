==================================================
SEMANTIC INTERPRETATION
==================================================

Use semantic interpretation ONLY when the object's identity is visually
unambiguous and supported by CLEAR, DIRECT evidence.

If you are NOT highly confident that a specific semantic identity is visible,
DO NOT name it. Prefer a generic physical description.

For example, a clearly recognizable STOP sign may be called a stop sign,
but a rectangular board with small unreadable text should remain a
"rectangular traffic sign with unreadable text."

Do NOT infer semantic meaning from:

• shape or colour alone
• text layout alone
• mounting position
• road location
• surrounding objects
• common traffic-sign conventions
• similarity to an ontology class

Do NOT call a sign bilingual, directional, information, route, one-way,
warning, regulatory, mandatory or prohibition unless that identity is
visually unmistakable.

Do NOT invent text, symbols, arrows, languages, countries, traffic rules
or unseen properties.

The description must answer:

"What can I actually see?"

not:

"What does this object probably mean?"

Do NOT assign the final ontology class or class ID.

UNCERTAINTY RULE

==================================================
TRAFFIC SIGN TEXT AND SYMBOLS
==================================================

If visible text cannot be read:

"text": "unreadable"

If a visible pictogram cannot be identified:

"symbol": "unreadable"

If no text is visibly present:

"text": "none"

If no symbol is visibly present:

"symbol": "none"

Never confuse "none", "unknown" and "unreadable".

Unreadable text does NOT automatically make the whole sign type unreadable.

If multiple scripts or visually distinct writing systems are clearly visible,
describe that visual fact without inventing their languages.

Do not claim a specific language unless visually identifiable.

OBJECT GROUP
==================================================

Every object must have exactly one object_group.

Use ONLY:

vehicle
road_user
animal
traffic_sign
traffic_signal
road_marking
road_infrastructure
infrastructure
temporary_object

object_group is the BROAD PHYSICAL CATEGORY, not the ontology class.

Examples:

bus/car/truck → vehicle
pedestrian/cyclist/rider → road_user
traffic sign → traffic_sign
traffic light → traffic_signal
crosswalk/lane divider/road arrow → road_marking
guardrail/bollard/delineator/median → road_infrastructure

Do NOT use fine-grained ontology class names as object_group.

Examples:

city_bus → vehicle
zebra_crossing → road_marking
Warning Sign → traffic_sign

Use "road_user" for people and human road participants.
Do NOT use "person" as object_group.
